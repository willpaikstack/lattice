# Vendor Equipment Figma Starting Point

This folder contains current-state reference assets for redesigning the Lattice OS `/equipment` page in Figma.

Files:

- `vendor-equipment-current-viewport.jpg` - current visible viewport screenshot.
- `vendor-equipment-current-fullpage.jpg` - full-page screenshot of the current equipment catalog.
- `vendor-equipment-expanded-viewport.jpg` - current visible viewport with the first equipment row expanded.
- `vendor-equipment-expanded-fullpage.jpg` - full-page screenshot with the first equipment row expanded.
- `vendor-equipment-current-figma-import.svg` - editable SVG approximation of the first viewport with callout comments.
- `vendor-equipment-redesign-comments.md` - comments and desired changes to paste into Figma or Figma AI.
- `equipment-card-states-for-figma-ai.md` - collapsed and expanded equipment card content/spec for Figma AI.
- `figma-ai-redesign-prompt.md` - editable prompt for collaborative iteration before pasting into Figma AI.

Suggested Figma workflow:

1. Create a new Figma design file.
2. Drag `vendor-equipment-current-viewport.jpg` into Figma as the visual reference.
3. Drag `vendor-equipment-current-figma-import.svg` into Figma if you want editable shapes/text plus callout notes.
4. Drag `vendor-equipment-expanded-viewport.jpg` beside it so Figma AI can see both collapsed and expanded row states.
5. Drag in `vendor-equipment-current-fullpage.jpg` or `vendor-equipment-expanded-fullpage.jpg` below the viewport references to preserve the full catalog context.
6. Edit `figma-ai-redesign-prompt.md` as needed, then paste it with the comments and `equipment-card-states-for-figma-ai.md` into Figma AI.

Note: Figma's native `.fig` file format is proprietary, so this repo provides Figma-importable source assets instead.
