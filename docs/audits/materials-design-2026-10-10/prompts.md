## Visual QA notes

All three show a coherent hierarchy, readable working content, and availability/reference caveats without invented numerical properties or stock/certification badges. Generated logo geometry differs from the official mark; reuse the real shared mark in implementation. A invents some grade examples (including Nitinol/MP35N in Precision alloys); replace all example copy from canonical data. B's condition dropdown renders T6 and T651 together; implementation must select one explicit reference condition at a time. Named exact citations and on-screen property values should be sourced from the real dataset in any prototype. These images illustrate layout, not a completed accessibility pass.
