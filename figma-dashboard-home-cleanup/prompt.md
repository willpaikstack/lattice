# Figma Prompt: Lattice OS Home Dashboard Cleanup

Use the attached screenshots as the source of truth for the current Lattice OS Home page at `http://localhost:3000/dashboard`.

Goal: clean up and improve the Home dashboard UI while preserving the same general layout, information hierarchy, and neutral B2B operations-console style.

Please create two design directions - you can add another page to the left sidebar. 

1. **Polish pass:** keep the current structure very close to the screenshot, but improve visual quality through spacing, typography, icon treatment, color balance, borders, hierarchy, table/list density, card surfaces, and interaction affordances.
2. **Modest layout improvement:** preserve the same page purpose and main sections, but propose thoughtful layout refinements that make the dashboard easier to scan and more useful for RFQ/order work.

Design constraints:

- Keep the experience neutral, operational, and professional.
- Avoid startup/marketing styling, decorative hero sections, oversized illustration, or loud gradients.
- Use a light background, restrained accents, clear status colors, and dense-but-readable information.
- Preserve the left sidebar app shell and the Home/Request Quote customer-workspace context.
- Treat Lattice OS as a manufacturing RFQ, quote, order, and procurement workflow product.
- Improve icons where helpful, but keep them utilitarian and consistent.
- Make cards, lists, and alerts feel like a serious B2B dashboard, not a generic template.
- Do not introduce admin-only peach branding here; this is the customer-facing Home page.

Important content to retain or improve:

- Greeting/header area.
- Top metrics for active RFQs, orders, shipped, and alerts.
- Inbox / notification stream.
- Activity or status sections shown lower on the page.
- Primary path to start a new quote/request.

Output requested:

- One refined desktop frame matching the current general layout.
- One alternate desktop frame with modest layout improvements.
- Optional notes explaining the highest-impact UI changes.
