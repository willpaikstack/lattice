These assets capture the current dropdown/select context for the Lattice OS `/requests/new` RFQ flow. Use them as Figma AI input when asking for a custom dropdown redesign.

## Design Notes

Lattice OS should feel like a premium B2B manufacturing operations console: light neutral surfaces, graphite text, quiet borders, restrained blue focus states, dense but readable forms, and manufacturing-specific option content. The current native selects should be replaced with a custom dropdown component system covering closed, hover, focus, open, selected, disabled, error, and long-list states.
