# Figma AI Context - Public Entry Pages

Use this folder as context for asking Figma AI to redesign the first pages a user sees in Lattice OS:

- `/` - invite-only public landing page
- `/login` - invite-only login page

Recommended files to upload/provide to Figma AI:

1. `figma-ai-first-pages-redesign-prompt.md` - main prompt to paste into Figma AI.
2. `product-and-design-context.md` - product, audience, tone, and constraints.
3. `current-ui-notes.md` - what exists today and what should change.
4. `current-homepage-viewport.jpg` and `current-login-viewport.jpg` - current visual references.
5. `current-homepage-fullpage.jpg` and `current-login-fullpage.jpg` - full-page visual references.
6. `current-home-page.tsx` and `current-login-page.tsx` - current implementation source for structural context.

PNG versions and DOM snapshots are included as secondary references if Figma AI handles those better than JPG/source.
