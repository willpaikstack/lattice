# Lattice Capabilities Figma Starting Point

This folder contains current-state reference assets for redesigning the Lattice OS `/capabilities` page in Figma.

Files:

- `lattice-capabilities-current-fullpage.png` - full-page screenshot of the current UI.
- `lattice-capabilities-current-figma-import.svg` - editable SVG approximation of the current page for importing into Figma.

Suggested Figma workflow:

1. Create a new Figma design file.
2. Drag `lattice-capabilities-current-fullpage.png` onto the canvas as the visual source of truth.
3. Drag `lattice-capabilities-current-figma-import.svg` onto the canvas if you want editable text/shapes as a rough starting point.
4. Paste the redesign prompt into Figma AI and reference the imported current UI as the starting point.

Note: Figma's native `.fig` file format is proprietary, so this repo provides Figma-importable source assets instead.
